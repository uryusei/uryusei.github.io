# Privacy Policy (Super Dashboard)

Super Dashboard is a personal tool used only by the owner of this GitHub account. It accesses only the owner's own Gmail account.

Access is read-only (Gmail scope: gmail.readonly). It never sends, deletes, or modifies email.

It records only the sender, subject, and date of messages. It does not store message bodies or attachments.

The records are stored only on the owner's own PC. No data is shared with, sold to, or transferred to any third party.

The owner can revoke access at any time from the Google Account permissions page.

# プライバシーポリシー

Super Dashboard は、この GitHub アカウントの持ち主だけが使う個人用ツールです。アクセスするのは持ち主本人の Gmail だけです。

読み取り専用です（gmail.readonly）。メールの送信・削除・変更はしません。

記録するのは差出人・件名・日時だけで、本文や添付ファイルは保存しません。

記録は持ち主の PC にだけ保存し、第三者への提供・販売・移転はしません。

アクセスは Google アカウントの設定からいつでも取り消せます。
